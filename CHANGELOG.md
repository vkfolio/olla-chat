# Changelog

All notable changes to this project will be documented in this file.

## [0.0.1] - 2026-03-03

- Added professional multi-mode chat UX (`Ask`, `Plan`, `Agent`) with streaming responses.
- Added selection-aware context and selection replacement apply/undo workflow.
- Added image attachment handling and vision model validation flow.
- Added debug logging and output channel command.
- Improved code block rendering with syntax tokens and copy action.
- Updated UI styling to follow VS Code theme tokens.
- Migrated UI icon set to Iconoir.
- Added Marketplace packaging metadata, README, changelog, activity icon, and VSIX packaging scripts.
